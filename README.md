# Mole Code

AI-агент для программирования: приложение для **Windows** и **Android**.

Скачать последнюю версию → **[Releases](../../releases/latest)**

| Платформа | Файл |
|---|---|
| Windows 10/11 (x64) | `MoleCode-Setup-x.y.z.exe` |
| Android 7.0+ | `MoleCode-x.y.z.apk` |

Установленное приложение само проверяет этот репозиторий и предлагает обновиться: появляется окно «Вышло обновление», файл скачивается с прогрессом и устанавливается. Обновление можно отложить и скачать позже в Настройках.

В каждом релизе лежат оба файла. Версия для ПК и для телефона берётся из имени файла.
