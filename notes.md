Mole Code 1.2 — a full redesign. **PC 1.2.0** and **Android 1.2.0**.

## ПК
- New quiet design: graphite panels, cards for the chat and the workbench, smooth animations
- The interface is in English by default; switch to Russian in Settings → General → Interface language (also on the welcome screen)
- The input looks like a clean field: attach, text and send inside; mode, access, project, model and reasoning sit under it — in the interface color, no green
- Reasoning level (Off / Low / Medium / High) for models that support it: Claude, GPT-5 and o-series, Gemini 2.5+, Qwen3, DeepSeek R1, gpt-oss and others
- Agent steps no longer have markers on the right — only a small spinner while a step is running
- Sidebar: New chat, Search, Commands, Settings; chats grouped by Today / Yesterday / This week / Earlier
- Demo mode answers in the interface language

## Телефон
- Same new design as on PC: graphite palette, calmer cards, softer press and appear animations
- English interface by default, Russian in Settings → Appearance → Interface language (and on the welcome screen)
- The input: attach, text, mic and send inside; mode, access, project, model and reasoning under it, in the interface color
- Reasoning level for models that support it
- Agent steps without markers — only a spinner while running

## Files
- `MoleCode-Setup-1.2.0.exe` — Windows 10/11 installer (x64)
- `MoleCode-1.2.0.apk` — Android 7.0 and newer
